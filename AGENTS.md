# Lumos for Astro

Read `LUMOS.md` before changing pages, components, or styles. This project uses
Lumos for Astro, not Lumos for Webflow. Compose pages from the components in
`src/components`; shared design tokens live in `src/styles/base.css`.

Run `npm run check` and `npm run build` after implementation changes.
The existing GitHub remote belongs to this project; preserve it.
